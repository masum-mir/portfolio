# Md Masum — Portfolio

A responsive portfolio featuring my software engineering projects, research, and experience.

[Live demo](https://masum-mir.github.io/portfolio/)

## Technologies

React, JavaScript, React Router, Sass, and Font Awesome.

## Features

- Home, Experience & Research, Projects, Education, and Contact pages
- Interactive 3D hero and project cards
- Scroll animations with reduced-motion support
- Resume and professional profile links

## Run locally

Requires Node.js and npm.

```bash
git clone https://github.com/masum-mir/portfolio.git
cd portfolio
npm install
npm start
```

The site runs at `http://localhost:3000`.
